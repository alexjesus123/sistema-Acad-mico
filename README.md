# Sistema de Gerenciamento Acadêmico

Projeto acadêmico de Programação Web I, com evolução até a Atividade 05.

## Execução
Baixe os arquivos e abra index.html no navegador.

## Recursos
Dashboard, listagens e formulários de alunos, cursos, matrículas e usuários. HTML5 semântico, validação nativa, CSS externo e Flexbox.

## Escopo
Protótipo estático: os formulários não salvam dados e o envio POST exige um servidor. Use dados fictícios. Sem JavaScript ou banco de dados.

## Desenvolvimento
Desenvolvido com auxílio de IA.
