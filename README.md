# Sistema de Gerenciamento Acadêmico

Projeto da disciplina Programação Web I — Aulas 09 e 10 e Atividade Avaliativa.

## Recursos
- JavaScript ES6+ (arrays, objetos, funções, filter, map, find, spread)
- DOM (querySelector, querySelectorAll, createElement, append, textContent, classList)
- Eventos (click, input, change, submit, preventDefault)
- Cadastro, busca, filtros, detalhes, remoção e mudança de status de alunos
- Dashboard atualizado automaticamente
- Persistência por JSON e LocalStorage, com try/catch e restauração de dados iniciais
- Listagens e cadastros de cursos, matrículas e usuários

## Arquivos
Páginas HTML na raiz, estilos em css/, dados.js, storage.js e app.js em js/.

## Como testar
Abra index.html ou o GitHub Pages. Cadastre um aluno, volte à listagem, atualize com F5, altere o status, remova e recarregue. Experimente Restaurar dados iniciais. Teste busca e filtro combinados. Use dados fictícios: LocalStorage não é banco de dados nem armazenamento seguro de senhas.

## Observação
Os registros ficam apenas no navegador/dispositivo de quem os criou.
